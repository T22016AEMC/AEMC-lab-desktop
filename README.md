# AEMC Lab Desktop

macOS 風格的虛擬桌面網頁，桌面是一座寵物養殖場，用來集中開啟部署在網路上的小程式（GitHub Pages / Render）並內建小遊戲。純前端，部署到 GitHub Pages。

正式網址：https://t22016aemc.github.io/AEMC-lab-desktop/

## 功能

- 開機畫面，點擊後直接進入桌面（不需要全螢幕）
- 頂部選單列（Logo →「關於這個桌面」、啟動台小圖示、作用中程式名稱、寵物數量與點數、日期時間）
- 桌面是像素風的寵物養殖場（見下方），畫面貼合瀏覽器可視區域（扣掉選單列），視窗縮放時即時重新計算；啟動台的入口是場景裡的住家（點門），備用入口是選單列小圖示與 F4；底部 Dock 平時隱藏，有內建視窗（小遊戲）開啟時才滑出
- 視窗系統（只給內建程式使用）：紅黃綠按鈕、拖曳、邊緣與角落縮放、雙擊標題列最大化、最小化動畫、置頂、同一程式只開一個視窗
- 外部程式一律用瀏覽器新分頁開啟；啟動台是使用者自己的程式清單，可新增、編輯（右鍵）、刪除（右鍵、需確認）、恢復預設程式，清單存在瀏覽器
- 電腦專用：可視寬度低於 1024px 時只顯示「本網站僅支援電腦瀏覽，請使用電腦開啟」，不載入桌面與養殖場
- 5 個內建小遊戲（踩地雷、2048、貪食蛇、彈珠台、飛機打怪），收在啟動台的「遊戲」資料夾
- PWA：可安裝成電腦的獨立視窗（`display: standalone`）

## 本機啟動

需要 Node.js 20.19 以上（建議 22）。

```bash
npm install
npm run dev        # 開發模式，網址 http://localhost:5173/
```

預覽正式建置的結果：

```bash
npm run build
npm run preview    # 網址 http://localhost:4173/
```

## 寵物養殖場（桌面）

桌面本身就是一個像素風的寵物養殖場：橫向草地，左下是住家、右邊是路燈、最右側後排是鐘樓，中間有 2 棵樹與少量固定的裝飾，天空隨日夜與天氣變化。**住家就是啟動台的入口**：滑鼠移到門上會開門、門牌發亮，點門開啟啟動台（備用入口：選單列的小圖示、快捷鍵 F4）。程式碼在 `src/farm/`。

**場景**
- 以像素素材繪製（Canvas 2D）。邏輯畫面約 480×270，用整數倍放大（`image-rendering: pixelated`，已處理 devicePixelRatio，不會模糊）；視窗更寬時天空與草地向左右延伸、不變形，底部貼地。層次由後到前：天空漸層 → 太陽／月亮 → 星星 → 雲 → 遠景 → 草地 → 後排物件（鐘樓、樹）→ 小路 → 前排物件與寵物（依腳底 y 排前後）。配置固定：住家在左下、路燈在住家右邊、鐘樓在最右側後排（周圍約 1.5 倍鐘樓寬度不放裝飾）、2 棵樹在中間偏左與偏右、裝飾物（灌木、蘑菇、石頭、小花叢）散布在小路兩側；視窗太窄時自動少放樹與裝飾。寵物不會走進住家、不會停在燈柱後面，鐘樓前方可以走。
- 日夜依本機實際時間（清晨 5–8、白天 8–17、黃昏 17–19:30、夜晚 19:30–5），天空顏色平滑過渡；夜晚加暗色疊層、住家亮燈、路燈發光、有星星與月亮。鐘樓的時鐘完全由程式畫（直徑約 48 的金框奶油色鐘面、12 個刻度、3／6／9／12 較粗），時間取自遊戲的時間來源（測試模式改時間時鐘面跟著變）：分針 = 分鐘×6（含秒的連續值）、時針 = (時%12)×30 + 分鐘×0.5，皆從 12 點鐘方向順時針量；夜晚鐘面不加暗，維持清楚可讀（`pixel/clock.ts`，有純函式測試：12:00、3:00、6:00、9:00、14:30、23:45、0:15）。
- 陸地寵物的睡覺時間是本機時間 23:00～隔天 6:00（`balance.ts` 的 `sleep`），與天空的日夜變化分開；黃昏與 23:00 前仍醒著正常活動。
- 天氣（晴、多雲、下雨、下雪）每 4 小時換一次，以時間為種子，重新整理不會跳變；純視覺效果，不連網。下雨是細長的淺藍色短線（1～2 像素寬、4～8 像素長）、下雪是小雪花素材、密度適中，不影響看寵物與選單。
- 固定的場景物件與位置在 `src/farm/pixel/layout.ts`（`sceneObjects`）；日後放其他建築的空位在 `buildingSlots`（本版不顯示）。

**寵物**
- 狗 6 個品種（柴犬、柯基、哈士奇、黃金獵犬、邊牧、貴賓）、貓 6 種花色／品種（橘虎斑、黑貓、三花、暹羅、英短藍貓、布偶貓），貓狗合計最多 6 隻，每隻領養 15 點，第一隻免費。領養視窗用「大家的正面照」像素圖當預覽。
- 每種動物只有一個外觀（不做胖瘦、幼年外觀）。體重、身高係數、「領養滿 3 天成年」只是數值，顯示在資訊裡。飽食度／心情／清潔度（0～100）隨時間緩慢下降；離開網站期間依經過時間補算，但最低不低於 20。
- 動作用像素幀播放：走路（walk_a／walk_b 交替）、待機（stand）、坐下、睡覺、吃東西、開心、梳毛；往左走水平翻轉，不旋轉、不縮放。行為邏輯（`pixel/pets.ts`）只決定「動作名稱」，名稱到幀的對應在 `ANIMS` 表，之後加玩耍動作只要新增名稱與幀。
- 頭上的狀態圖示：餓＝驚嘆號、心情低＝汗滴、髒＝泡泡、睡覺＝ZZZ、開心＝愛心。

**操作**
- 點寵物，頭上彈出氣泡選單：名字、三條像素風小條（飽食、心情、清潔）與所有操作（每次 1 點）：餵食、撫摸、洗澡、散步（狗）、梳毛（貓）、叫醒（睡覺中）。點空白處關閉。睡覺時：撫摸可用（不會醒來，心情 +5）；叫醒可用（貓醒來不開心心情 −15，狗醒來很開心心情不變）；其他顯示「正在睡覺，可以先叫醒」。若仍在睡覺時間內，約 10 分鐘沒有任何互動就會自己回去睡。
- 滑鼠移到寵物身上：牠會看向滑鼠並輕輕跳一下。
- 選單列右側「＋領養」按鈕，旁邊是寵物數量（例如 3/6）與點數；畫面左下不放任何浮動按鈕。寵物之間有分散機制（互相避讓、草地與小路都會去），六隻同場時重疊比例很低。
- 點數：初始 30，每日第一次開啟 +5（以本機日期判斷）；心情高於 70 的寵物每天最多 4 次叼來禮物，點擊領取 +1～3 點。

### 像素素材與處理管線

遊戲用的像素素材在 `public/assets/`（圖集 PNG ＋ `manifest.json`：每張的位置、尺寸、錨點、動畫幀順序）。原圖是 AI 生成的洋紅底像素風圖，放在 repo 外的資料夾（預設是 repo 上一層的「像素風圖片」，已加進 `.gitignore`，不進 repo）。要重新產生素材：

```bash
node scripts/process-assets.mjs "<原圖資料夾>"      # 或設定環境變數 ASSET_SRC
```

腳本會：① 去背（洋紅底、細白框、格線；alpha 只有 0 或 255）② 依檔案的欄×列切成單張，錨點 = 水平中心＋腳底基準線（同一隻動物各姿勢腳底對齊）③ 還原真像素：估算原圖的像素格大小，以最近鄰重新取樣成 1 格 = 1 像素，狗與貓共用同一個像素格大小，所有素材像素密度一致 ④ 把遠景、小路左右鏡像拼成可水平重複，草地方塊以 2×2 鏡像拼成可上下左右無縫 ⑤ 打包圖集、產生 manifest、處理報告 `screenshots/assets-report.txt` 與總覽圖 `screenshots/assets-overview.png`（及 -dark／-light）。

**像素規格**（單位：邏輯像素，1 個像素 = 原圖 1 格；每個素材各自取樣，同一隻動物所有姿勢共用同一個取樣比例）：場景邏輯解析度約 480×270（寬度夠時放大 2 倍以上並向左右延伸）；狗站姿高 黃金獵犬 46 ＞ 哈士奇 43 ＞ 邊牧 41 ＞ 柴犬 36 ＞ 貴賓 34 ＞ 柯基 31（柯基寬度仍大）；貓站姿高 布偶 33 ＞ 英短藍貓 32 ＞ 暹羅 31 ＞ 橘虎斑 30 ＞ 三花 29 ≈ 黑貓 28；住家 139×134、鐘樓 123×160、樹 82×103、路燈 51×84；裝飾高 蘑菇 37、樹樁 36、灌木 40、高草叢 38、石頭 34、小花叢 28；狀態與特效圖示統一約 15 高。處理報告有前後尺寸對照表。開發環境有「比例對照圖」（測試模式裡的 📏 按鈕或網址 `?proportions`），把 12 隻動物與住家、樹、鐘樓、路燈用同一個比例並排。動作名稱：狗 stand／walk_a／walk_b／sit_a／sit_b／sleep／eat／happy＋jump／dig_a／dig_b／tug／belly_up／bark；貓 stand／walk_a／walk_b／sit_a／（unused_back：背面，不使用）／sleep／eat／groom＋crouch／pounce／swat／tangled。建築、玩具、玩耍用的素材已處理好放在 manifest 裡，本版畫面上不使用。

**存檔**
- 單一物件（含 `schemaVersion`），目前存在 localStorage（鍵名 `aemc-desktop:farm-save`，遊戲最高分沿用舊鍵名，不衝突）。
- 儲存層是 `SaveStorage` 介面（`load`／`save`／`clear`，皆為 Promise），目前實作 `LocalStorageAdapter`，讀寫都包在 try/catch。之後改成帳號綁定的雲端存檔時，只需實作同一介面並呼叫 `setSaveStorage()`。資料格式升級時在 `src/farm/save/migrate.ts` 依 `schemaVersion` 轉換。
- 數值、容量、點數等調整參數集中在 `src/farm/config/balance.ts` 與 `species.ts`。
- 存檔寫入失敗（瀏覽器空間已滿等）時會顯示提示，不會靜默忽略。舊版（v2 以前）存檔讀取時自動升級：海洋生物移除並退還點數。

**測試模式（只在本機開發環境）**
`npm run dev` 時畫面右下角會有「🧪 測試模式」面板：點數 +100／+1000、時間快轉 1 小時／1 天、調整寵物各項數值與體重、切換天氣與時段、讓寵物叼禮物、重置養殖場，以及「生物圖鑑」（列出 12 隻動物的所有像素幀）。它透過 `import.meta.env.DEV` 條件式動態載入，正式 build 會被整段移除（`npm run build` 後 `dist/` 內搜尋不到任何測試模式的程式碼）。

**預留給後續階段**：建築購買與建築功能（澡盆、蹺蹺板、沙坑、篝火、野餐墊、食盆水盆、花圃、狗窩、貓跳台；素材已處理好，位置保留在 `buildingSlots`）、「玩耍」互動、使用程式賺點數、拍照。

## 管理程式（啟動台）

外部程式清單是使用者自己的，存在瀏覽器（`aemc-desktop:app-list`，含 `schemaVersion`，透過 `src/lib/documentStorage.ts` 的可替換儲存層，之後可搬到帳號雲端）。

- 新增：啟動台右上角的「＋」→ 填網址（沒寫 http 會自動補 https，只接受 http／https）、名稱、圖示（上傳圖片會置中裁成正方形並縮成 256×256，或使用文字圖示：名稱前 1～2 個字、顏色依名稱雜湊決定）。
- 編輯、刪除：在程式圖示上按右鍵（刪除前會確認）。預設的 5 個程式也可以編輯與刪除；內建遊戲只能「隱藏」。
- 「恢復預設程式」：還原成預設清單並重新顯示隱藏的遊戲。
- 所有外部程式都用新分頁開啟（`window.open`，帶 `noopener,noreferrer`），所以不需要檢查網站能不能嵌入。

預設的 5 個程式（FilMaster、SpecReader、CheMScutter、EluSim、AutoEllipso）定義在 [src/config/apps.ts](src/config/apps.ts) 的 `DEFAULT_APPS`；圖片圖示放在 `public/icons/`，`icon` 寫 `'icons/檔名.png'`，寫 `''` 則是文字圖示。

## 內建程式與小遊戲

`src/config/builtinApps.ts` 用來登錄「內建程式」：直接在桌面視窗中渲染 React 元件。元件會收到 `active`（是否為作用中視窗）與 `minimized`（是否最小化）兩個屬性。`category: 'games'` 的程式會歸入啟動台的「遊戲」資料夾，不顯示在桌面圖示，只有開啟時才出現在 Dock。

目前的 5 個遊戲（程式碼在 `src/games/<遊戲名稱>/`，共用的暫停、結算畫面、音效、縮放畫布在 `src/games/shared/`）：

| 遊戲 | 資料夾 | 操作 |
| --- | --- | --- |
| 踩地雷 | `minesweeper` | 初級 9×9、中級 16×16、高級 30×16；左鍵翻開、右鍵插旗、點數字快速翻開。最高紀錄是各難度的最短時間 |
| 2048 | `game2048` | 方向鍵或 WASD |
| 貪食蛇 | `snake` | 方向鍵或 WASD；分數越高速度越快 |
| 彈珠台 | `pinball` | Z／← 左擋板、/／→ 右擋板；按住空白鍵蓄力、放開發射；也可以點畫面左半邊或右半邊控制擋板、用「發射」按鈕蓄力。物理使用 matter-js，3 顆球 |
| 飛機打怪 | `shooter` | 自動射擊；方向鍵、WASD 或拖曳移動。每 5 波一隻 Boss；P 火力升級（最高 5 級）、S 護盾 |

共通行為：

- 全部用 Canvas 或 React 繪製，沒有外部圖片；畫面隨視窗大小縮放。
- 有開始畫面、暫停（P 或 Esc）、遊戲結束畫面。視窗最小化、不是作用中視窗、分頁隱藏或瀏覽器失去焦點時會自動暫停。
- 最高分存在 localStorage（鍵名 `aemc-desktop:<遊戲>:best`），讀寫都有 try/catch，無痕模式也不會出錯。
- 音效用 WebAudio 合成，預設關閉，視窗右上角的喇叭按鈕可開關。

新增遊戲的做法：在 `src/games/<名稱>/index.tsx` 寫一個接收 `BuiltinAppProps` 的元件（可用 `useGameStatus` 與 `GameShell`），再到 `builtinApps.ts` 登錄。

## 部署到 GitHub Pages

1. 把專案推送到 GitHub（repo 名稱 `AEMC-lab-desktop`）。
2. 到 repo 的 **Settings → Pages**，**Source** 選 **GitHub Actions**。
3. push 到 `main` 分支後，[.github/workflows/deploy.yml](.github/workflows/deploy.yml) 會自動 build 並部署。
4. 部署完成後網址為 `https://<帳號>.github.io/<repo 名稱>/`。

Vite 的 `base` 讀取環境變數 `BASE_PATH`；Actions 會自動帶入 `/<repo 名稱>/`，本機開發則為 `/`。若要改用其他 repo 名稱，不需要修改程式。

## 版本管理

每次修改程式都要更新 `package.json` 的 version 與 [CHANGELOG.md](CHANGELOG.md)，並 commit、打 tag，詳見 [CLAUDE.md](CLAUDE.md)。「關於這個桌面」顯示的版本號與更新日期，是建置時分別從 `package.json` 與 CHANGELOG 最上方的紀錄讀取。

## 專案結構

```
scripts/         process-assets.mjs（像素素材處理管線）
public/assets/   處理後的像素素材圖集與 manifest
src/
├─ farm/          寵物養殖場：config（物種、數值）、save（存檔與儲存層）、sim（純邏輯）、store、pixel（像素場景：assets 素材、layout 版面、scene 背景、pets 行為、engine 引擎）、ui（領養視窗、氣泡選單、像素小圖）
├─ dev/           測試模式面板（只在開發環境載入）
├─ config/        apps.ts（外部程式清單）、builtinApps.ts（內建程式）、registry.ts
├─ store/         windowStore.ts（視窗管理）、uiStore.ts（開機、啟動台、版面尺寸）
├─ components/    BootScreen、MenuBar、AboutDialog、Desktop、Dock、Launchpad、Window …
├─ games/         minesweeper、game2048、snake、pinball、shooter、shared（共用元件）
├─ hooks/         useClock、useMediaQuery、useViewportSync、useLaunchpadHotkey
└─ lib/           layout、format、icon、dock、documentStorage、appUrl、iconImage
```
