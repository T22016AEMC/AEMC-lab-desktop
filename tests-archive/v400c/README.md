# v4.0 階段 C：晴天娃娃、房屋與鐘樓配件、傳說展示台

不接進主專案的 npm scripts，也不是 CI。設計與規格見 `CLAUDE.md` 的「階段 C」。

| 檔案 | 用途 |
|---|---|
| `node/v400c-features-entry.js`、`runall.sh` | Node 測試（`bash tests-archive/v400c/runall.sh`）：天氣機率（40 萬個區段，有／沒娃娃，絕對值 ±5%、沒娃娃和舊公式逐區段相同、`worldWeather` 是唯一入口且 6 處呼叫都傳存檔）、配件資料／商店／購買／掛上／切換／取下／存檔來回／舊存檔相容／圖集、配件位置逐外觀不蓋門窗與鐘面、傳說展示台（事件、補送、只送一次、半對不送、台面顯示與切換、不佔 decorTotal、擺放與存檔） |
| `browser/tc1-browser.mjs`、`run-browser.mjs` | 瀏覽器測試（自己開 dev server，port 5197）：商店配件分組（買、掛上、換、取下、買一次、重新整理維持、1366×282）、配件畫在房屋與鐘樓上（快照比對）、傳說展示台（舊存檔載入補送一次、半對不送、台面顯示、點擊切換並存檔、只有一對不能切換、倉庫裡有展示台）。截圖在 `browser/shots/`（不進 git） |
| `adapt-c.py` | 對既有測試的預期值異動（可重複執行），見下表 |
